# mastema.tech Agent Guidance

## Overview
Static website using Bootstrap 5.1.3 via Start Bootstrap Small Business template.
No build system, tests, or development dependencies.

## Development
- Edit `index.html` for content and structure
- Modify `css/styles.css` for styling (Bootstrap variables already defined)
- Add custom JavaScript to `js/scripts.js` (currently blank)
- Place additional assets in `assets/` directory

## Previewing Changes
Open `index.html` directly in a web browser to view changes.
No local server required for basic preview.

## Important Notes
- Bootstrap CSS is customized via CSS variables in styles.css
- Favicon located at `assets/favicon.ico`
- Template is MIT licensed (see LICENSE file)
- No special setup or installation needed
